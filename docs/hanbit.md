# 한빛커뮤니티 소모임 신청 (/hanbit)

- 신청 화면: `/hanbit`, 관리자: `/hanbit-admin` (대관 관리와 같은 관리자 비밀번호). 장소대관은 없고 소모임 신청만 받습니다.
- 마두 소모임(`/crew`)과 같은 화면과 규칙(한 달 10,000원, 시간대마다 정원 10명, 당일 노쇼 환불 불가, 연장 안내)을 쓰고, 색만 초록 계열입니다(`public/hanbit.css`).
- 데이터는 마두 소모임과 완전히 따로 저장됩니다(저장소 키 접두어 `hb:`). 같은 요일·시간이어도 정원이 섞이지 않습니다.
- 설정은 `public/shared/hanbit-config.mjs` 한 곳입니다. 소모임, 요일·시간, 참가비, 정원, 안내문을 고치면 됩니다.
  - 같은 이름의 소모임이 여러 지역에 있으면 한 장의 카드로 묶어서 모든 요일·시간을 보여 줍니다. 지역(부서) 이름은 화면과 문자에 나오지 않습니다.
  - `flexible: true`인 소모임(바이올린)은 정해진 시간이 없어 신청 대신 "일정은 문의 후 정해요" 안내를 보여 줍니다.
- 사진: `public/photos/hanbit/프로그램ID-번호.jpg` (png, webp도 됩니다). 프로그램 ID는 설정 파일에 있습니다(예: `knot-1.jpg`, `calli-2.jpg`).
- 문자: 대관, 마두 소모임과 같은 Solapi 설정을 쓰고 머리말은 `[한빛커뮤니티]`입니다.
- 계좌와 문의 번호(선택): Render 환경변수 `HANBIT_BANK_NAME`, `HANBIT_BANK_NUMBER`, `HANBIT_BANK_HOLDER`, `HANBIT_CONTACT_PHONE`을 넣으면 한빛 전용으로 쓰고, 없으면 공용 `BANK_*`, `CONTACT_PHONE`을 씁니다.
- 연장 안내 자동 발송(`/api/crew-cron`)은 마두 소모임과 한빛커뮤니티를 함께 처리합니다.
