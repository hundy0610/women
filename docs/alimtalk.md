# 카카오 알림톡 연결 (Solapi)

예약자에게 두 번 알림톡이 갑니다.

1. **송금 안내**: 예약을 마친 직후. 계좌, 금액, 입금 기한.
2. **송금 완료**: 관리자가 예약 목록에서 "입금 확인"(확정)을 누른 때. 이미 확정된 예약은 다시 보내지 않습니다.

입금은 은행 연동이 아니라 관리자가 확인해 누르는 방식이라, "송금 완료" 알림은 그 버튼에 연결됩니다.
설정이 비어 있으면 아무것도 보내지 않고, 발송이 실패해도 예약은 그대로 처리됩니다(Render 로그에 `[alimtalk]`로 남음).

## 준비 순서

1. 카카오톡 비즈니스 채널 만들기 (비즈니스 인증 필요)
2. [Solapi](https://solapi.com) 가입 후 충전, 카카오 채널 연동, 발신번호 등록
3. 아래 템플릿 2개를 Solapi 콘솔에서 등록하고 카카오 심사 통과(보통 영업일 1~3일)
4. API Key 만들기
5. Render 환경변수에 아래 값을 넣고 재배포

| 환경변수 | 값 |
| --- | --- |
| `SOLAPI_API_KEY`, `SOLAPI_API_SECRET` | Solapi 콘솔의 API Key |
| `SOLAPI_SENDER` | 등록한 발신번호 (숫자만) |
| `KAKAO_PF_ID` | 연동한 카카오 채널의 pfId (콘솔의 카카오 채널 관리에서 확인) |
| `ALIMTALK_TEMPLATE_PAY` | 송금 안내 템플릿 ID |
| `ALIMTALK_TEMPLATE_PAID` | 송금 완료 템플릿 ID |

`BANK_NAME`, `BANK_NUMBER`, `BANK_HOLDER`는 예약 화면에 쓰는 값을 그대로 씁니다.

## 템플릿 문구 (예시)

변수는 `#{이름}`이 아니라 아래 영문 이름으로 등록합니다.
사용할 수 있는 변수: `name`, `date`, `time`, `space`, `amount`, `bank`, `account`, `holder`, `deadline`, `id`

### 송금 안내

```
[여성문화센터] 대관 예약 접수 안내

#{name}님, 예약이 접수되었습니다.

■ 일시: #{date} #{time}
■ 공간: #{space}
■ 금액: #{amount}

아래 계좌로 #{deadline}까지 입금해 주세요.
#{bank} #{account} (예금주 #{holder})

기한 안에 입금이 확인되지 않으면 예약이 자동으로 취소됩니다.
```

### 송금 완료

```
[여성문화센터] 대관 예약 확정 안내

#{name}님, 입금이 확인되어 예약이 확정되었습니다.

■ 일시: #{date} #{time}
■ 공간: #{space}
■ 금액: #{amount}

이용 당일 뵙겠습니다. 감사합니다.
```

알림톡은 정보성 문구만 허용되고, 홍보 문구가 들어가면 심사에서 반려됩니다.
카카오톡을 쓰지 않는 번호로는 도착하지 않고, 대체 문자는 보내지 않도록 되어 있습니다(`disableSms`).
