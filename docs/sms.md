# 예약자 문자 알림 (Solapi)

예약자 휴대전화로 문자가 두 번 갑니다. 카카오 채널이나 사업자 서류 없이 쓸 수 있도록 알림톡 대신 문자로 보냅니다.

1. **송금 안내**: 예약을 마친 직후. 일시, 공간, 금액, 계좌, 입금 기한.
2. **송금 완료**: 관리자가 예약 목록에서 "입금 확인"(확정)을 누른 때. 이미 확정된 예약은 다시 보내지 않습니다.

입금은 은행 연동이 아니라 관리자가 확인해 누르는 방식이라, "송금 완료" 문자는 그 버튼에 연결됩니다.
설정이 비어 있으면 아무것도 보내지 않고, 발송이 실패해도 예약은 그대로 처리됩니다(Render 로그에 `[sms]`로 남음).

## 준비 순서

1. Solapi 가입 후 잔액 충전
2. 콘솔에서 **발신번호 등록과 인증**
   - 문자는 사전에 등록한 번호로만 보낼 수 있습니다. 필요한 서류는 번호 종류에 따라 다르니 Solapi 안내를 따르세요.
3. 콘솔에서 **API Key** 만들기
4. Render 환경변수에 넣고 재배포

| 환경변수 | 값 |
| --- | --- |
| `SOLAPI_API_KEY`, `SOLAPI_API_SECRET` | Solapi 콘솔의 API Key |
| `SOLAPI_SENDER` | 등록한 발신번호 |
| `SMS_NOTIFY` | (선택) `off`로 두면 문자를 보내지 않음 |

`BANK_NAME`, `BANK_NUMBER`, `BANK_HOLDER`는 예약 화면에 쓰는 값을 그대로 씁니다.
켜졌는지는 관리자 → 설정 → "예약자 문자"에서 봅니다.

## 문자 내용

둘 다 단문(SMS, 건당 18원, VAT 별도)으로 나가도록 줄여 썼습니다.

```
[송금 안내]
[여성문화센터] 10/22 10~13시 세미나실 90,000원
국민 123-456-789012
10/20 12시까지 입금

[송금 완료]
[여성문화센터] 10/22 10~13시 세미나실 예약 확정
```

- 공간을 여러 개 고르면 "세미나실 외2"처럼 줄입니다.
- 계좌는 은행 이름 끝의 "은행"을 빼고 쓰며, 예금주는 넣지 않습니다.
- 90바이트(한글 약 45자)를 넘으면 자동으로 장문(LMS, 건당 45원)으로 나갑니다. 은행 이름이 길거나 공간 이름이 길 때 그럴 수 있습니다.

## 문구 고치기

`lib/sms.js`의 `payGuideText`, `paidText` 두 함수입니다. 문자는 템플릿 심사가 없어 고치고 푸시하면 바로 바뀝니다.
