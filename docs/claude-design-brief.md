# Claude Design 전달용: 드림 문화센터 대관 예약 사이트 전체 리디자인

아래 "1. 붙여 넣을 프롬프트"를 Claude Design에 먼저 붙여 넣고, 이 문서의 나머지(2~9번)를 함께 첨부하세요.

---

## 1. 붙여 넣을 프롬프트

```
첨부한 문서는 "드림 문화센터 대관 예약" 사이트의 현재 구조입니다. 예약 화면(예약자용)과 관리자 화면 전체를
새로 디자인해 주세요.

[해 줄 일]
1. 문서 2~7번의 모든 화면(예약 6단계, 입금 안내, 내 예약 조회·취소, 오시는 길 창, 사진 확대 창,
   관리자 로그인과 7개 탭)을 빠짐없이 디자인합니다. 화면 목록에서 빠지는 것이 없어야 합니다.
2. 화면마다 모바일(375px), 태블릿(768px), 데스크톱(1280px) 세 가지를 만들어 주세요.
   예약자의 대부분은 휴대폰을 쓰므로 모바일을 먼저 완성하고 나머지를 맞춥니다.
3. 먼저 디자인 시스템을 정하고(색, 글꼴, 글자 크기, 간격, 모서리, 그림자, 버튼·카드·입력칸·칩·배지·표·달력·
   시간표·사진 줄·알림 띠·대화상자·빈 화면·오류 화면), 그 시스템으로 모든 화면을 만듭니다.
4. 각 화면의 상태도 보여 주세요: 기본, 선택됨, 비활성, 로딩, 오류, 비어 있음, 성공.

[바꿔도 되는 것]
색, 글꼴, 레이아웃 배치, 컴포넌트 모양, 아이콘, 일러스트, 모션, 화면 안의 정보 배치와 위계.

[바꾸면 안 되는 것]
- 화면 수와 이동 순서(예약 6단계 → 입금 안내), 각 단계에서 받는 정보와 버튼의 기능.
- 새 기능을 만들지 마세요. 문서에 없는 화면이나 입력 항목을 더하지 않습니다.
- 한국어 문구의 뜻. 말투는 다듬어도 되지만 정보를 빼지 마세요(요금, 계좌, 기한, 안내 문장).
- 사진은 실제 공간 사진이 들어갑니다(자리표시 이미지로 대체하지 말고 사진 칸을 비워 두세요).

[사용자]
- 예약자: 40대~70대 여성이 많습니다. 글자는 크게(본문 18px 이상), 대비는 높게(WCAG AA 4.5:1 이상),
  터치 대상은 44px 이상, 한 화면에 질문 하나. 어렵거나 장식적인 표현은 피합니다.
- 관리자: 센터 담당자 한 명이 PC와 휴대폰으로 하루 한두 번 입금 확인·취소를 처리합니다. 빠르게 훑고 누르는 것이 중요합니다.

[분위기]
믿음이 가고 따뜻하며 요즘 느낌이 나는 공공·커뮤니티 서비스. 차분하지만 밋밋하지 않게.
현재 색은 바이올렛 계열이지만 바꿔도 됩니다. 단, 상태를 색만으로 구분하지 말고 글자나 아이콘을 함께 쓰세요.

[기술 조건]
프레임워크 없이 정적 HTML, CSS, 자바스크립트로 구현됩니다. 이미지·글꼴은 가볍게, 글꼴은 한국어 가변 글꼴(현재 Pretendard)
또는 이에 준하는 무료 글꼴을 쓰고, 어떤 글꼴을 썼는지 알려 주세요. 다크 모드는 선택 사항입니다.

[결과물]
- 디자인 시스템 정리표(색 이름과 값, 글자 크기표, 간격, 모서리, 그림자)
- 모든 화면의 시안(모바일, 태블릿, 데스크톱)
- 컴포넌트별 상태 시안
- 구현자가 바로 쓸 수 있는 CSS 변수 목록
```

## 2. 서비스 개요

- 이름: **드림 문화센터 대관 예약**. 센터의 공간(로비, 세미나실, 방 3개)을 시간 단위로 빌려주는 예약 사이트.
- 주소: 예약 화면은 `/`, 관리자는 `/admin`.
- 예약 흐름: 날짜 → 공간 → 시간 → 인원 → 예약자 정보 → 확인 → **입금 안내**. 결제는 온라인이 아니라 계좌 이체이고, 담당자가 입금을 확인하면 예약이 확정됩니다.
- 입금 기한: 예약 후 24시간. 기한이 지나면 자동 취소(기한 만료).
- 이용 24시간 전까지 신청, 오늘부터 90일 뒤까지 예약 가능, 최소 2시간.
- 운영 시간 09~21시. 수요일·일요일은 휴무(예약 불가). 센터 행사 등으로 특정 날짜를 막을 수 있음(휴관일).
- 예약 확정과 입금 안내는 예약자 휴대폰으로 문자 발송.

### 공간과 요금

| 공간 | 평수 | 인원 | 시간당 | 1일(8시간 이상) | 설명 |
| --- | --- | --- | --- | --- | --- |
| 로비 | 23.3평 | 50명 | 3만원 | 20만원 | 원목 테이블과 벤치, 트랙 조명, 전시 월 (스탠딩) |
| 세미나실 | 38.1평 | 60명 | 3만원 | 20만원 | 강연, 해설, 워크숍용 가장 넓은 공간 (좌식) |
| 방1 | 9.7평 | 12명 | 2만원 | 13만원 | 유리 파티션 독립 공간, 트랙 조명 |
| 방2 | 9.7평 | 12명 | 2만원 | 13만원 | 같음 |
| 방3 | 9.7평 | 12명 | 2만원 | 13만원 | 같음 |

- 공간마다 사진 3장.
- "전체 통대관" 선택: 5개 공간 전체, 1일 70만원(개별 합계보다 할인).
- 최대 인원을 넘으면 1인당 1만원 추가.
- 요금 예: 세미나실 3시간 = 9만원, 방1 + 방2 하루 = 26만원, 전체 8시간 = 70만원.

## 3. 사이트 지도

```
예약자용 (/)
├─ 1 날짜          ─ 달력
├─ 2 공간          ─ 공간 카드 5장 + "전체 통대관" 카드
├─ 3 시간          ─ 시작·종료 시간 선택(모바일은 칩, 데스크톱은 시간표)
├─ 4 인원          ─ 인원 입력, 이용 목적
├─ 5 예약자        ─ 이름, 휴대전화
├─ 6 확인          ─ 요약, 요금, 동의, [예약 신청하기]
├─ 7 입금 안내      ─ 금액, 계좌, 예약번호, 안내 3줄
├─ 8 내 예약 조회   ─ 예약번호 + 휴대전화로 조회, 취소
├─ 오시는 길 창     ─ 주소, 지도, 교통, 복사 버튼
└─ 사진 확대 창     ─ 전체 화면, 좌우로 넘기기

관리자 (/admin)
├─ 로그인
└─ 7개 탭: 예약 목록 · 달력 · 이력 · 직접 등록 · 휴관일 · QR 코드 · 설정
```

(참고: `/docs/manual.html`은 담당자용 운영 매뉴얼 문서 한 장입니다. 같은 디자인 시스템으로 읽기 쉬운 문서 페이지로 만들어 주세요.)

## 4. 예약자 화면: 공통 틀

### 머리글
- 왼쪽: (2단계 이후) 뒤로 가기, 로고 "드림 문화센터"(글자 로고), 작은 라벨 "대관 예약".
- 오른쪽: 데스크톱은 "대관 문의 전화번호", **오시는 길**, **내 예약**. 모바일은 오시는 길, 내 예약만.
- 진행 표시: 모바일은 얇은 진행 막대(1/6~6/6). 데스크톱(1000px 이상)은 6개 단계 탭(날짜, 공간, 시간, 인원, 예약자, 확인). 현재 단계 강조, 지난 단계는 체크.

### 본문과 하단
- 단계마다 큰 제목 하나, 한 줄 설명, 입력 영역.
- **하단 고정 영역(dock)**: 위에 선택 요약 한 줄(예: "10월 22일(목) · 세미나실 · 예상 90,000원"), 큰 주 버튼, 그 아래 한 줄 안내 문구(버튼이 비활성인 이유).
- 주 버튼 문구는 단계마다 다릅니다: 날짜 단계 "공간 고르기", 공간 "시간 정하기", 시간 "인원 정하기", 인원 "예약자 정보 입력", 예약자 "내용 확인하기", 확인 "90,000원 예약 신청하기"(금액 포함), 입금 안내 "확인했어요".
- 데스크톱(1000px 이상)은 2열: 왼쪽 작업 영역, 오른쪽 **요약 패널**(스크롤해도 따라옴).

### 오른쪽 요약 패널 (데스크톱만)
1. "내 예약" 카드: 날짜, 공간, 시간, 인원(선택 전에는 "선택 전"), 요금 계산 줄(공간별, 전체 할인, 인원 초과), **예상 요금**(가장 크게).
2. 선택한 날짜의 "공간별 현황" 카드: 공간 5개 × 09~20시 칸(예약 가능 / 입금 대기 / 예약 완료 / 휴무 범례).
3. "입금 안내" 카드: 24시간 안에 입금, 계좌.

### 알림 띠(머리글 아래, 필요할 때만)
- 최근 예약이 있으면: "최근 예약 10월 22일(목) 09:00~12:00 · 90,000원" + [입금 안내 보기]
- 오류: "예약 저장소가 아직 설정되지 않아 예약할 수 없습니다." / "예약 현황을 불러오지 못했습니다." + [다시 불러오기]

## 5. 예약자 화면: 단계별 내용

### 1단계 날짜 — "언제 이용하실 건가요?"
- 설명: "이용 24시간 전까지 신청할 수 있어요."
- 달력 한 달(이전·다음 달 버튼). 날짜 칸 상태: 선택됨, 오늘, 지난 날(비활성), 휴무(수·일, 빗금 또는 라벨 "휴무"), 마감(예약이 가득 참, 라벨 "마감"), 예약이 있는 날(작은 점).
- 범례: 오늘 / 예약 있음 / 휴무.
- 버튼 "공간 고르기"(날짜 선택 전 비활성, 안내 "이용하실 날짜를 먼저 골라 주세요.").

### 2단계 공간 — "어떤 공간이 필요하세요?"
- 설명: "10월 22일(목) · 여러 공간을 함께 고를 수 있어요."
- **공간 카드 5장**(각 카드: 사진 줄, 이름, 인원, 평수, 시간당 요금과 1일 요금, 그날 이용 가능 시간 "12시간 가능" 또는 "예약 불가", 선택 체크 표시).
  - 사진 줄: 사진 3장을 옆으로 밀어서 넘김, 오른쪽 아래 "1/3" 표시, 사진을 누르면 전체 화면 확대 창.
  - 선택하면 카드 강조(테두리, 체크).
- 맨 아래 **"전체 통대관"** 카드(5개 공간 일괄 선택, 요금 70만원/8시간).
- 버튼 "시간 정하기"(공간 선택 전 비활성, "공간을 하나 이상 골라 주세요.").

### 3단계 시간 — "몇 시부터 몇 시까지 쓰실까요?"
- 설명: "최소 2시간부터 신청할 수 있어요."
- **모바일**: "시작 시간" 칩 줄(09:00~19:00 등, 불가 시간은 비활성·취소선) → 시작을 고르면 "종료 시간" 칩 줄 → 접이식 "이날 예약 현황".
- **데스크톱**: 시간 칸(09~20시)을 시간표에서 누르는 방식. 시작 칸을 누르고 끝 칸을 누르면 사이가 선택됨. 칸 상태: 예약 가능, 선택 범위, 입금 대기, 예약 완료, 휴무.
- 결과 줄: "09:00 ~ 12:00 (3시간)".
- 버튼 "인원 정하기".

### 4단계 인원 — "몇 분이 오시나요?"
- 설명: "최대 60명, 초과 시 1인당 10,000원"(선택한 공간에 따라 바뀜).
- 인원 입력: 큰 숫자 + [−][+] 버튼, 빠른 선택 칩(5, 10, 20, 30, 50명).
- 이용 목적(선택): 칩(독서 모임, 전시, 강연, 워크숍, 회의) + "직접 입력" 칸.
- 버튼 "예약자 정보 입력".

### 5단계 예약자 — "예약하시는 분을 알려 주세요"
- 입력: 이름, 휴대전화(숫자 키패드, 010-0000-0000 형식 안내).
- 안내: "입금하실 분 이름과 같게 적어 주세요. 연락처는 예약 안내와 확인에만 써요."
- 오류 표시: 이름 2자 이상, 번호 형식.
- 버튼 "내용 확인하기".

### 6단계 확인 — "마지막으로 확인해 주세요"
- 요약 카드: 일정, 공간, 인원, 예약자.
- 요금 카드: 공간별 요금 계산 줄, 전체 할인(마이너스), 인원 초과 요금, **입금할 금액**(가장 크게).
- 체크박스: "내용을 확인했어요. 24시간 안에 입금하시면 예약이 확정돼요. 문의 010-0000-0000"
- 버튼 "90,000원 예약 신청하기"(체크 전 비활성, 안내 "이용 안내 확인에 체크하세요."), 처리 중 "신청하는 중…".
- 실패 시(이미 예약됨 등) 빨간 안내 + 시간 다시 선택 유도.

### 7단계 입금 안내 — "입금해 주세요"
- 설명: "입금이 확인되면 예약이 확정됩니다."
- 성공 표시(체크 아이콘), **금액**(가장 크게) + [금액 복사].
- **입금 계좌 카드**: 은행명, 계좌번호, 예금주, [계좌번호 복사하기](누르면 "복사됐어요"로 바뀜).
- 예약 정보 카드: 예약번호, 일정, 공간, 입금자명, 입금 기한.
- 번호 목록 3줄: 입금자명 안내 / 기한이 지나면 자동 취소 / 예약번호는 조회·취소에 필요하니 캡처.
- 버튼 "확인했어요"(처음으로).

### 8단계 내 예약 조회·취소 (머리글의 "내 예약")
- 입력: 예약번호(8자리 영숫자), 휴대전화 → 버튼 "내 예약 찾기".
- 결과 카드: 상태 배지(입금 대기 / 확정 / 취소 / 기한 만료 / 취소 요청 중), 일정, 공간, 금액, (입금 대기면) 입금 기한과 입금 계좌 카드와 복사 버튼.
- 취소: [예약 취소] → 확인 영역(사유 입력 선택) → [취소하기] [돌아가기]. 안내 문구가 다릅니다: 입금 전은 "바로 취소됩니다", 확정은 "담당자가 확인한 뒤 취소하고 환불합니다"(취소 요청으로 접수).
- 결과 후 버튼 "확인했어요".

### 오시는 길 창(대화상자)
- 주소, 가까운 역·도보 시간, 지도(네이버 지도 임베드 또는 지도 앱 열기 버튼), [주소 복사], 대중교통 안내 문장, 대관 문의 전화(눌러서 전화), 사업자 정보(있을 때).

### 사진 확대 창
- 전체 화면 어두운 배경, 가운데 사진, 닫기(X), 좌우 화살표, 하단 "세미나실 1 / 3". 좌우로 밀어서 넘김, 배경을 누르면 닫힘. 밝은 사진 위에서도 버튼이 보여야 함.

## 6. 관리자 화면

### 공통 틀
- 데스크톱: 왼쪽 사이드바(로고 + "관리", 7개 메뉴, 맨 아래 나가기) + 오른쪽 본문. 모바일: 위 머리글 + 가로로 밀리는 메뉴.
- 본문 맨 위: 작은 날짜 줄("10월 19일(월) · 오늘 이용 2건"), 페이지 제목(탭 이름), 필요한 도구(예약 목록은 "카드/목록" 보기 전환).
- 결과 알림(토스트) 한 줄: 성공은 초록, 오류는 빨강.

### 로그인
- 로고, "예약 관리", "관리자 비밀번호를 입력하세요.", 비밀번호 칸, 오류 문구, [들어가기].

### 탭 1 예약 목록 (기본)
- **통계 카드 4장**: 입금 대기(건수, 합계 금액) / 확정 예약(건수, 이번 달 금액) / 오늘 이용(건수, 날짜) / 취소 요청(건수, 환불 처리 필요 안내, 0건이면 "없음"). 취소 요청이 있으면 경고 느낌으로 강조.
- 상태 필터(칩, 건수 표시): 입금 대기 / 취소 요청 / 확정 / 기한 만료 / 취소 / 전체. 기본은 "입금 대기".
- 검색칸: 이름, 전화번호, 예약번호.
- **선택 취소 막대**: "전체 선택(현재 목록 N건)" 체크박스, "N건 선택됨", [선택 해제], [선택 취소 (N)](선택이 없으면 비활성). 일부만 선택하면 전체 선택 체크박스가 중간 상태.
- **예약 행(카드)**: 왼쪽 체크박스, 날짜(굵게)와 시간, 이름과 공간(+ "메모 있음"), 입금 대기면 "입금 기한 23시간 남음"(6시간 미만이면 경고 색), 금액, 상태 배지. 입금 대기 행에는 [입금 확인(확정)] 빠른 버튼.
  - 행을 누르면 펼쳐짐: 예약번호(직접 등록이면 표시), 연락처(눌러서 전화), 인원, 이용 목적, 접수 시각, 취소 요청 정보(시각, 사유), 입금 기한, **관리자 메모** 입력과 [메모 저장], 버튼들([입금 확인(확정)], [취소 요청 반려], [취소] 또는 [취소 승인(환불 후 처리)]), 이 예약의 변경 이력 목록.
- 보기 전환: "카드"(넉넉한 카드) / "목록"(한 줄씩 촘촘하게).
- 빈 목록: "해당하는 예약이 없습니다."
- 확인 창: 입금 확인 시 "○○님이 90,000원을 입금한 것을 통장에서 확인했나요?", 취소 시 사유 입력 창.

### 탭 2 달력
- 월 이동(이전, 다음, 오늘), 월 제목. 7열 달력, 날짜 칸 안에 그날의 예약 태그(확정은 진한 색, 입금 대기는 연한 노랑, 휴관 라벨). 오늘과 선택한 날 강조.
- 범례: 확정 / 입금 대기 / 휴관.
- 날짜를 누르면 아래에 "그날의 예약" 목록(시간, 이름·공간, 금액, 상태).

### 탭 3 이력
- 제목 "변경 이력" + 안내("예약 생성, 확정, 취소, 메모, 비밀번호 변경이 시간순으로 남습니다…").
- 시간순 목록: 시각, 행위(예약 접수·입금 확인·취소·메모 수정·취소 요청·휴관일 추가 등), 상세(이름·공간, 메모).
- 빈 상태: "아직 이력이 없습니다."

### 탭 4 직접 등록
- 안내(전화·방문 접수용, 24시간 규칙과 하루 3건 제한은 적용 안 됨, 같은 시간 중복은 막힘).
- 폼: 날짜, 공간(체크 칩 5개), 시작/종료(드롭다운), 이름, 휴대전화, 인원, 이용 목적, 체크박스 "입금 확인 완료(확정으로 등록)", 실시간 금액 표시, 오류 줄, [등록하기].

### 탭 5 휴관일
- 안내(공휴일·센터 행사·공사로 막을 날짜 지정, 수·일은 기본 휴무).
- 폼: 시작일, 종료일, 사유(예약 화면에 표시, 예: "추석 연휴"), [휴관일 추가].
- 등록된 휴관일 목록(기간, 사유, [해제]).

### 탭 6 QR 코드
- 안내 + 2열: 왼쪽 폼(주소, QR 아래 문구, [PNG 내려받기] [SVG 내려받기] [인쇄], 도움말), 오른쪽 **QR 미리보기 카드**(QR, 문구, 주소). 인쇄 시 QR 카드만 출력.

### 탭 7 설정
- 카드 3장: **비밀번호 변경**(새 비밀번호, 확인, [비밀번호 변경]), **내보내기**([CSV 내려받기]), **예약자 문자**(연결 상태 문장), **새 예약 알림**(연결 상태 문장, [테스트 알림 보내기]).

## 7. 상태 색 규칙 (의미는 유지, 색과 모양은 바꿔도 됨)

| 상태 | 의미 | 표시 |
| --- | --- | --- |
| 입금 대기 | 예약했고 입금을 기다림 | 노랑 계열 + 글자 "입금 대기" |
| 확정 | 입금 확인됨 | 초록(민트) 계열 + "확정" |
| 취소 | 취소됨 | 회색 + "취소" |
| 기한 만료 | 24시간 안에 입금 안 됨 | 회색 + "기한 만료" |
| 취소 요청 | 확정 후 예약자가 취소 요청, 환불 필요 | 빨강(코랄) 계열 + "취소 요청" |
| 휴무·휴관 | 예약 불가 날 | 연한 회색 + 빗금 또는 "휴무" |
| 예약 완료(현황표) | 이미 다른 예약이 있는 칸 | 진한 색 + "예약" |

상태는 색만으로 전달하지 말고 글자나 아이콘을 함께 쓰세요.

## 8. 현재 디자인 (참고용, 바꿔도 됨)

- 색: 브랜드 바이올렛 `#6C47E0`(진한 `#4E2FB5`), 글자 짙은 인디고 `#1E1B3B`, 보조 `#484466`/`#5F5B7B`, 선 `#E4DFF2`, 바탕 라일락 `#F4F1FC`, 강조 노랑 `#FFC53D`(연한 `#FFF2CF`), 확정 민트 `#0B7A5B`, 경고 코랄 `#B42318`.
- 글꼴: Pretendard Variable. 크기 7단계(제목 34px/800, 부제목 22px/700, 본문 18px/400, 라벨 18px/600, 작은 글자 16px, 캡션 15px, 금액 40px/800).
- 모서리: 카드 14~24px, 버튼은 알약형, 입력칸 14px.
- 로고: 글자만. "드림"은 굵게 바이올렛, "문화센터"는 보통 굵기 인디고, 끝에 작은 노란 점.
- 아이콘: 선 아이콘(Lucide 계열) 인라인 SVG.
- 느낌: 연한 오로라 배경 위에 흰 카드, 유리 머리글, 모바일 하단에 떠 있는 둥근 버튼 영역.

## 9. 지켜야 할 조건 (요약)

1. 화면 수, 순서, 입력 항목, 버튼 기능은 그대로.
2. 모바일 우선, 375 / 768 / 1280 세 가지.
3. 본문 18px 이상, 대비 4.5:1 이상, 터치 44px 이상, 상태는 색만으로 구분하지 않기.
4. 사진 칸은 실제 사진용(비율 16:8 정도, 카드 위쪽), 아이콘은 선 스타일 SVG.
5. 모든 화면의 비어 있음·오류·로딩 상태 포함.
6. 정적 HTML/CSS/JS로 구현 가능한 수준(복잡한 3D·무거운 애니메이션 제외), `prefers-reduced-motion` 고려.
