# 화면 디자인 개선 보고

기준: 가독성, 깔끔함, 모던함. 참고 방향은 Toss의 "한 화면 한 질문"과 Apple의 "여백과 큰 글씨". **색은 그대로**(tokens.css 변경 없음)이고 글자, 여백, 모서리, 그림자, 배치만 바꿨습니다.

## 1. 진단: 이전 화면의 문제

| 문제 | 왜 불편했나 |
|---|---|
| 화면을 채우려고 카드를 억지로 늘림 | 사진이 가로로 길게 잘리고, 글자와 빈칸의 비율이 어색했음 |
| 규칙이 겹겹이 쌓임(수백 줄의 덮어쓰기) | 화면마다 간격과 크기가 제각각이고 수정할 때 서로 충돌 |
| 모든 곳에 2px 테두리와 알약 버튼 | 시각 잡음이 많고 눈이 갈 곳이 없음 |
| 단계 표시가 알약 4개 + 진행 막대 + 문구 | 같은 정보를 세 번 보여 줌 |
| 하단 버튼 바가 흰 판으로 화면을 가림 | 내용이 잘려 보이고 답답함 |
| 영수증성 정보가 두 칸 격자 | 라벨과 값을 눈으로 이어 읽기 힘듦 |
| 아이콘이 얇고 균일해 구분이 약함 | 작은 크기에서 모양 구분이 어려움 |

## 2. 새 디자인 원칙

1. **가운데 한 칸**: PC에서도 입력과 확인 화면은 560~640px 한 칸. 시선이 흩어지지 않습니다.
2. **여백이 위계를 만든다**: 제목 40px(PC) / 30px(폰), 본문 18~19px, 보조 글씨 15~16px. 섹션 사이 24~36px.
3. **선 대신 면과 그림자**: 카드는 테두리 없이 아주 옅은 그림자와 24px 둥근 모서리. 선택된 카드는 파란 3px 링.
4. **큰 버튼 하나**: 하단 버튼 바는 배경 없이 버튼만 떠 있고(높이 62px, 모서리 18px), 위에 한 줄 안내만 둡니다.
5. **영수증 목록**: 항목명은 왼쪽 회색, 값은 오른쪽 굵게, 사이는 가는 구분선.
6. **입력칸은 크고 조용하게**: 높이 60px, 20px 글씨, 옅은 테두리, 눌렀을 때만 파란 링.
7. **움직임은 절제**: 화면 전환 0.3초 페이드업, 버튼 누름 0.985배, `prefers-reduced-motion`이면 끔.

## 3. 화면별 변경

- **처음 화면**: 큰 질문 + 큰 카드 두 장(공간 대관 / 소모임 신청). 카드 위에 올리면 살짝 떠오름.
- **소모임·공간 목록**: 사진을 왼쪽에 크게(172px), 오른쪽에 이름 → 시간별 정원 → 가격. PC 2열, 폰 1열. 사진은 옆으로 밀어 넘기기 유지.
- **일정(달력)**: 달력은 테두리 없는 둥근 칸. 선택한 날은 파란 칸, 오늘은 얇은 링. PC에서는 오른쪽에 요일·시간, 요약, 수업 날짜.
- **신청자 정보**: 큰 입력칸 두 열(PC). "필수/선택" 표시는 작은 라벨.
- **확인**: 영수증 카드 + 안내(노란 면) + 동의 체크. PC에서는 두 열.
- **입금 안내**: 금액, 계좌, 신청 내용, 번호가 붙은 안내를 두 열로.
- **하단 버튼**: 모든 화면에서 같은 위치, 같은 크기.

## 4. 아이콘

Phosphor Icons(MIT, 오픈소스)로 교체했습니다. 둥글고 부드러운 모양이고, 체크·화살표·더하기처럼 작게 쓰는 기호는 굵은(bold) 모양으로 또렷하게 했습니다. 외부에서 불러오지 않고 코드에 넣어서 보안 정책(CSP)과 속도에 영향이 없습니다. 자세한 내용은 `docs/icons.md`.

## 5. 구조 개선(개발)

- `styles.css`: 기본 부품만 남기고 덮어쓰기 규칙 300줄 제거.
- `ui.css`(신규): 고객 화면 전용 디자인. 관리자 화면은 영향받지 않습니다.
- 사진 카드, 영수증 목록, 큰 버튼 바를 한 곳에서 관리하므로 앞으로 수정이 쉽습니다.

## 6. 이번에 하지 않은 것(다음 제안)

1. 관리자 화면(`/admin`, `/crew-admin`)의 같은 톤 적용: 지금은 아이콘만 새 체계.
2. 입금 완료 화면의 계좌 번호 큰 글씨 복사 버튼 강조.
3. 소모임 카드 상세(사진 확대, 소개 문구) 화면.
4. 글자 크기 키우기 버튼(어르신 사용자 대상) 추가.

## 7. 확인 방법

- PC 1440×900, 폰 390×844에서 전 단계를 열어 확인했습니다(가로 스크롤 없음).
- 폰트는 Pretendard를 그대로 사용(자체 호스팅).
